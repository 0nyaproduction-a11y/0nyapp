# 0nya shared authority

For every task, apply this precedence order:

1. Current task and explicit user decisions.
2. Approved 0nya project, product, and technical authority in the root `AGENTS.md` and its referenced documents.
3. Root `AGENTS.md`.
4. Root `KARPATHY_GUIDELINES.md`.
5. Kilo defaults.

Read the root `AGENTS.md` before acting. Use `KARPATHY_GUIDELINES.md` as generic behavior guidance only after 0nya authority is satisfied. Do not change application code, dependencies, or unrelated files unless the current task requires it. Preserve existing rules and report unrelated problems instead of fixing them automatically.
